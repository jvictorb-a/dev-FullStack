## 💡 Sobre o Projeto

Este laboratório foca na manipulação de coleções de dados no front-end. O projeto armazena um array estático de nomes e disponibiliza duas funcionalidades principais:
1. **Listagem Completa (`loadNames`):** Percorre o array utilizando estruturas de repetição para renderizar dinamicamente todos os elementos em formato de lista estilizada com Bootstrap.
2. **Busca Filtrada (`searchNames`):** Captura o valor digitado pelo usuário em um campo de input e realiza uma varredura condicional no array, exibindo na tela apenas os registros correspondentes.

O desenvolvimento reforça a importância da manipulação direta do DOM (`innerHTML`) e da organização de comportamentos em funções reutilizáveis.
