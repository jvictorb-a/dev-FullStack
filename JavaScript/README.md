# JavaScript

Este diretório reúne meus estudos, exercícios e projetos desenvolvidos em JavaScript durante minha formação como Desenvolvedor Full Stack.

Embora eu já possuísse conhecimento prévio dos fundamentos mais básicos da linguagem, decidi iniciar a documentação dos meus estudos a partir deste módulo para acompanhar minha evolução técnica de forma organizada e consistente.

O propósito desta seção é registrar o aprendizado contínuo, consolidar conceitos fundamentais e intermediários da linguagem e aplicar esses conhecimentos na construção de soluções práticas.

## Objetivos

- Fortalecer os conhecimentos em JavaScript.
- Aprimorar a lógica de programação e resolução de problemas.
- Compreender conceitos fundamentais e intermediários da linguagem.
- Aplicar boas práticas de desenvolvimento.
- Construir uma base sólida para tecnologias do ecossistema JavaScript, como Node.js, TypeScript, React e Next.js.

## Organização

### Aulas

Contém códigos desenvolvidos durante o estudo dos conteúdos e exemplos utilizados para compreender os conceitos apresentados.

### Exercícios

Contém exercícios resolvidos individualmente com o objetivo de praticar, revisar e consolidar os conhecimentos adquiridos.

### Projetos

Contém aplicações práticas desenvolvidas para transformar teoria em experiência, aplicando os conceitos estudados em cenários mais próximos do desenvolvimento real.

## Conteúdos

Ao longo deste módulo são abordados temas como:

- Fundamentos da linguagem
- Operadores e expressões
- Estruturas condicionais
- Estruturas de repetição
- Funções
- Arrays
- Objetos
- Orientação a Objetos
- Métodos nativos
- Manipulação do DOM
- Eventos
- Boas práticas de desenvolvimento
- Conceitos intermediários de JavaScript

## Metodologia

A organização desta pasta segue uma abordagem baseada em três etapas:

```text
Estudar → Praticar → Aplicar
```

Os conceitos são estudados por meio das aulas, reforçados através de exercícios e consolidados na construção de projetos práticos.

## Considerações

Esta documentação representa meu processo de aprendizado e evolução como desenvolvedor. O conteúdo será atualizado continuamente à medida que novos conhecimentos forem adquiridos e novos projetos forem desenvolvidos.
